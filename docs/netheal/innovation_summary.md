# NetHeal-Agent 创新总结

## 五项核心创新

1. **多智能体分层诊断**：将告警解析、拓扑关联、根因定位、修复决策和验证评估拆分为五类专业角色，并复用 Co-Sight 的 DAG 并发调度。
2. **拓扑增强证据链**：根因结论同时携带告警事件、KPI 阈值、拓扑影响和知识规则 ID，可追溯故障从根网元到业务切片的传播路径。
3. **多源融合根因排序**：使用结构化规则对告警、KPI 和历史案例进行交叉验证，降低只看单条高等级告警造成的症状误判。
4. **风险分级的人机协同修复**：仿真环境可自动闭环，生产变更必须进入人工审批工单，并提供默认 dry-run 命令和回滚策略。
5. **验证失败自动回溯**：修复后按 SLA 检查 KPI；未恢复时回到根因候选排序，最多重试两次，避免“生成建议即结束”的伪闭环。

## 技术难点与解决方式

- 多源数据格式不同：统一由工具输出带来源字段的 JSON 证据。
- DAG 并发与步骤依赖：直接使用 Co-Sight `Plan` 的依赖图，不引入第二套调度器。
- 大模型结果不稳定：根因排序、修复验证和评测采用确定性代码，大模型负责规划、解释与工具选择。
- 自动修复安全风险：默认仿真、人工审批、审计工单和回滚命令四层保护。
- 无真实 5G 网管环境：用可替换的数据适配层构建比赛闭环，后续保持工具 schema 不变接入真实 API。

## 推广前景

工具内部的数据访问层可替换为运营商 NMS、Prometheus、拓扑 CMDB、知识库和工单系统。相同 DAG 可推广到园区专网、矿山专网、港口专网和工业 5G 网络，并通过新增规则与适配器扩展故障类型。
